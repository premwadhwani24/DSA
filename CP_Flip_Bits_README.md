# CP_Flip_Bits

Solution to the Codeforces problem "Flip the Bits".

## Problem
There is a binary string `a` of length `n`. In one operation, you may select any prefix of `a` that contains an equal number of `0` and `1` symbols, then invert every symbol in that prefix.

The task is to determine whether it is possible to transform string `a` into string `b` using zero or more such operations.

## Input
- `t` test cases
- For each test case:
  - `n` — length of the strings
  - binary string `a`
  - binary string `b`

## Output
- Print `YES` if transformation is possible.
- Print `NO` if it is impossible.
